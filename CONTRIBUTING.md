# Contributing

Please don't.

This is a personal project. The code was written by an AI and its author cannot review
it, let alone review yours. There is no support, and updates are unlikely.

| | |
|---|---|
| **Issues** | Most likely never read. |
| **Pull requests** | Will not be merged. |
| **Security problems** | See `SECURITY.md`. The honest summary is the same. |
| **Using the code yourself** | It is MIT licensed. Fork it and do what you like; you need nobody's permission, and you will get nobody's help. |

**Never attach a real photo or video to anything in this repository.**
